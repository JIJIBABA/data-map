# 前端更新发布（搜索框功能）

## 这次更新内容
表详情页字段列表新增**模糊搜索框**，支持按字段名/注释实时过滤。

---

## 发布步骤（3 步，无需停后端）

### 第 1 步：上传更新包

开发机上的更新包：
```
D:\self\data-map\frontend-update.zip   (542KB)
```

用 **WinSCP / Xftp** 把它传到服务器 `/home/scfadmin/`。

### 第 2 步：服务器上替换前端文件

SSH 登录 `12.0.216.77`（scfadmin 账号），执行：

```bash
# 进入家目录
cd ~

# 解压更新包到一个临时目录
rm -rf frontend-update-tmp
mkdir frontend-update-tmp
unzip frontend-update.zip -d frontend-update-tmp

# 替换部署目录的 dist（先删旧的，再拷新的）
rm -rf ~/datamap/frontend/dist
cp -r frontend-update-tmp ~/datamap/frontend/dist

# 确认文件到位
ls -la ~/datamap/frontend/dist/
ls -la ~/datamap/frontend/dist/assets/
```

> 如果提示 `unzip: command not found`，先装：`sudo yum install -y unzip`

### 第 3 步：浏览器验证

打开 **http://12.0.216.77:8966/**

⚠️ **必须按 `Ctrl + Shift + R` 强制刷新**（清浏览器缓存，否则还显示旧页面）

验证：
1. 进任意表详情页
2. 字段列表上方应该有搜索框"搜索字段名或注释"
3. 输入关键词（如 `order`、`金额`），表格实时过滤

---

## 为什么不用重启后端？

前端是**静态文件**，后端 Spring Boot 实时读取 `~/datamap/frontend/dist/` 目录。换掉 dist 文件后，浏览器刷新就能加载新页面，**不用停 java 进程、不用重启**。

---

## 一键命令（熟了直接复制）

```bash
cd ~ && rm -rf frontend-update-tmp && mkdir frontend-update-tmp && \
unzip frontend-update.zip -d frontend-update-tmp && \
rm -rf ~/datamap/frontend/dist && \

echo "前端已更新，浏览器 Ctrl+Shift+R 强刷"
```
